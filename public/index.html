Stremio Local Debrid

Your computer downloads and caches torrents from your Stremio addons, then streams them to your TV over your local network.

Install in Stremio

Set up the local server first, then paste its private addon address below. This address stays in your browser.

Install in Stremio

Why this exists

A slow TV can struggle to download torrents and play video at the same time. This addon moves torrent downloading and storage to a computer on your home network. Install the server locally, then connect Stremio on the TV to it.

git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup

The setup wizard generates your private config.json and offers automatic startup on macOS, Linux and Windows. On macOS, sign in to Stremio 5 with the TV's account; on Linux and Windows, enter addon URLs in the wizard. To configure a server that runs in a terminal, use:

npm run setup -- --no-service
npm start
