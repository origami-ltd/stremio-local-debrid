# Stremio Local Debrid — Ελληνικά

Ο υπολογιστής κατεβάζει και αποθηκεύει torrents από τα πρόσθετα Stremio και μεταδίδει το βίντεο στην τηλεόραση μέσω του τοπικού δικτύου.

## Γιατί υπάρχει

Μια αργή τηλεόραση δυσκολεύεται να βρίσκει peers, να κατεβάζει τμήματα torrent και να παίζει βίντεο ταυτόχρονα. Το Stremio Local Debrid μεταφέρει τη λήψη και αποθήκευση στον υπολογιστή. Η τηλεόραση λαμβάνει βίντεο HTTP μέσω του οικιακού δικτύου. Ελέγχετε τη δική σας μνήμη χωρίς πληρωμένο λογαριασμό debrid στο cloud.

## Πώς λειτουργεί

Ο διακομιστής ζητά πηγές από εγκατεστημένα πρόσθετα και διατηρεί τις ρυθμίσεις τους. Hashes, magnets και σύνδεσμοι .torrent γίνονται πηγές τοπικής κρυφής μνήμης. Η επιλογή ξεκινά τη λήψη στον υπολογιστή και μεταδίδει το επιλεγμένο αρχείο στην τηλεόραση. Τα διπλότυπα μοιράζονται μνήμη και trackers. Άμεσοι σύνδεσμοι βίντεο και εξωτερικές υπηρεσίες δεν μετατρέπονται.

## Απαιτήσεις

Χρειάζονται Node.js 24 ή νεότερο, ελεύθερος χώρος και υπολογιστής και τηλεόραση προσβάσιμα στο ίδιο δίκτυο. Η αυτόματη ανίχνευση λογαριασμού υποστηρίζει Stremio 5 για macOS. Linux και Windows χρησιμοποιούν χειροκίνητη λίστα πρόσθετων. Κύριες συσκευές είναι Android TV, Google TV και Fire TV· άλλοι πελάτες μπορεί να χρειάζονται HTTPS και συμβατούς κωδικοποιητές.

## Εγκατάσταση διακομιστή

Εκτελέστε npm run setup για να δημιουργήσετε config.json και να ρυθμίσετε την εκκίνηση σε macOS, Linux ή Windows. Σε macOS, συνδεθείτε στο Stremio 5 με τον λογαριασμό της TV· σε Linux/Windows, εισαγάγετε τα URL των πρόσθετων στον οδηγό. Το --yes δέχεται τις προεπιλογές, το --no-service αποθηκεύει μόνο τη ρύθμιση και το --lang επιλέγει γλώσσα. Τα υπάρχοντα tokens και οι λήψεις διατηρούνται.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup
```

```sh
npm run setup -- --no-service
npm start
```

## Σύνδεση τηλεόρασης

Ανοίξτε τη διεύθυνση από state/status-url.txt, επιλέξτε γλώσσα και Εγκατάσταση στο Stremio ή επικολλήστε τη διεύθυνση στο πεδίο εγκατάστασης. Χρησιμοποιήστε τον ίδιο λογαριασμό στην τηλεόραση και ανανεώστε πρόσθετα ή επανεκκινήστε το Stremio. Επιλέξτε Τοπική κρυφή μνήμη για ταινία ή επεισόδιο. Οι αρχικές πηγές χρησιμοποιούν ακόμη τη συσκευή που τις ανοίγει. Η λίστα συγχρονίζεται κάθε 60 δευτερόλεπτα.

## Μνήμη και αναπαραγωγή

Οι λήψεις συνεχίζονται μετά το κλείσιμο του player και επανέρχονται μετά την επανεκκίνηση του διακομιστή. Κατεβαίνει μόνο το επιλεγμένο αρχείο. Προεπιλογή: 100 GiB μνήμη και 10 GiB δεσμευμένου ελεύθερου χώρου· ολοκληρωμένα, σπάνια χρησιμοποιούμενα torrents αφαιρούνται όταν χρειάζεται χώρος. Η εκκίνηση εξαρτάται από peers και δίκτυο. Δεν γίνεται μετακωδικοποίηση: η τηλεόραση αποκωδικοποιεί το βίντεο. Κρατήστε τον υπολογιστή ενεργό και προσβάσιμο. Αν αλλάξει η IP, ενημερώστε baseUrl και επανεγκαταστήστε το πρόσθετο.

## Απόρρητο και άδεια

Η διεύθυνση περιέχει ιδιωτικό token: μην το δημοσιεύετε σε αναφορές ή στιγμιότυπα. Το macOS διαβάζει το υπάρχον προφίλ και στέλνει το κλειδί συνεδρίας μόνο στο επίσημο API Stremio χωρίς να αποθηκεύει αντίγραφο. Οι ρυθμισμένες διευθύνσεις αποθηκεύονται ιδιωτικά. Δεν υπάρχει κατάλογος μέσων ή τηλεμετρία. Τα peers βλέπουν την IP του υπολογιστή. Χρησιμοποιήστε περιεχόμενο στο οποίο έχετε δικαίωμα πρόσβασης.
