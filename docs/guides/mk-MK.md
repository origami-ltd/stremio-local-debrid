# Stremio Local Debrid — Македонски

Компјутерот презема и чува торенти од вашите Stremio додатоци и го пренесува видеото до телевизорот преку локалната мрежа.

## Зошто постои

Бавен телевизор може да има тешкотии истовремено да бара peers, да презема делови од торент и да пушта видео. Stremio Local Debrid ги префрла преземањето и чувањето на компјутерот. Телевизорот добива HTTP видео преку домашната мрежа. Управувате со свој кеш без платена облачна debrid сметка.

## Како работи

Серверот бара извори од инсталираните додатоци и ги задржува нивните поставки. Хешови, magnet врски и .torrent врски стануваат извори од локален кеш. Изборот започнува преземање на компјутерот и ја пренесува избраната датотека до телевизорот. Дупликатите делат кеш и обединети trackers. Директни видео врски и надворешни услуги не се претвораат.

## Барања

Потребни се Node.js 24 или понов, слободен простор и компјутер и телевизор достапни во иста мрежа. Автоматското откривање сметка поддржува Stremio 5 за macOS. Linux и Windows користат рачен список додатоци. Главни уреди се Android TV, Google TV и Fire TV; други клиенти може да бараат HTTPS и соодветни кодеци.

## Инсталација на серверот

На macOS најавете се во Stremio 5 со сметката на телевизорот. На Linux или Windows извршете npm run setup, додајте ги конфигурираните URL адреси на manifest во sources во config.json и поставете autoDiscoverAddons: false. На трите системи извршете npm run install:service. Серверот стартува и автоматски се вклучува при најава преку LaunchAgent, systemd или Распоредувачот на задачи. Stremio може да биде затворен.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run install:service
```

```sh
npm run setup
npm start
```

## Поврзување на телевизорот

Отворете ја адресата од state/status-url.txt, изберете јазик и Инсталирај во Stremio или залепете ја адресата во полето за инсталација. На телевизорот користете ја истата сметка, освежете ги додатоците или рестартирајте Stremio. За филм или епизода изберете Локален кеш. Оригиналните извори и понатаму го користат уредот што ги отвора. Списокот се синхронизира на секои 60 секунди.

## Кеш и репродукција

Преземањата продолжуваат по затворање на плеерот и се обновуваат по рестарт на серверот. Се презема само избраната датотека. Стандардно има 100 GiB кеш и 10 GiB резервиран слободен простор; завршени, ретко користени торенти се бришат кога треба простор. Почетокот зависи од peers и мрежата. Нема транскодирање: телевизорот го декодира видеото. Држете го компјутерот буден и достапен. При промена на IP ажурирајте baseUrl и повторно инсталирајте го додатокот.

## Приватност и лиценца

Адресата содржи приватен токен: не објавувајте го во пријави или слики. macOS го чита постојниот профил и го праќа клучот на сесијата само до официјалниот Stremio API без да чува копија. Конфигурираните адреси се чуваат приватно. Нема медиумски каталог или телеметрија. Peers може да ја видат IP адресата на компјутерот. Користете содржина до која имате право на пристап.
