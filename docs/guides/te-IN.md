# Stremio Local Debrid — తెలుగు

మీ కంప్యూటర్ Stremio యాడ్‌ఆన్‌ల టొరెంట్లను డౌన్‌లోడ్ చేసి నిల్వ చేస్తుంది, ఆపై స్థానిక నెట్‌వర్క్ ద్వారా టీవీకి వీడియో పంపుతుంది.

## ఇది ఎందుకు ఉంది

నెమ్మదిగా ఉండే టీవీకి ఒకేసారి టొరెంట్ డౌన్‌లోడ్ చేయడం, వీడియో ప్లే చేయడం కష్టమవచ్చు. Stremio Local Debrid డౌన్‌లోడ్, నిల్వ పనిని కంప్యూటర్‌కు మారుస్తుంది. టీవీ ఇంటి నెట్‌వర్క్‌లో HTTP వీడియో అందుకుంటుంది. చెల్లింపు క్లౌడ్ debrid ఖాతా లేకుండానే కాష్ మీ నియంత్రణలో ఉంటుంది.

## ఇది ఎలా పనిచేస్తుంది

సర్వర్ అనుకూలంగా ఉన్న ఇన్‌స్టాల్ చేసిన యాడ్‌ఆన్‌ల చిరునామాలు, సెట్టింగ్‌లను అలాగే ఉంచి స్ట్రీమ్ మూలాలను అడుగుతుంది. టొరెంట్ హ్యాష్, magnet, .torrent లింకులు స్థానిక కాష్ మూలాలవుతాయి. మూలం ఎంచుకుంటే కంప్యూటర్‌లో డౌన్‌లోడ్ మొదలవుతుంది. ఒకే ఫైల్‌కు కాష్ ఉమ్మడిగా ఉంటుంది; ట్రాకర్లు కలుస్తాయి. నేరుగా వీడియో లింకులు, బాహ్య సేవలు మార్చబడవు.

## అవసరాలు

Node.js 24 లేదా కొత్తది, తగిన ఖాళీ డిస్క్, ఒకే అందుబాటులోని నెట్‌వర్క్‌లో కంప్యూటర్, టీవీ అవసరం. ఖాతా స్వయంచాలక గుర్తింపు macOSలో Stremio 5కు ఉంది. Linux, Windowsలో యాడ్‌ఆన్ జాబితా చేతితో ఇవ్వాలి. Android TV, Google TV, Fire TV ప్రధాన లక్ష్యాలు; ఇతర క్లయింట్లకు HTTPS, అనుకూల codec అవసరమవచ్చు.

## సర్వర్ ఏర్పాటు

config.json సృష్టించి macOS, Linux లేదా Windowsలో ప్రారంభాన్ని కాన్ఫిగర్ చేయడానికి npm run setup అమలు చేయండి. macOSలో TV ఖాతాతో Stremio 5లో లాగిన్ చేయండి; Linux/Windowsలో విజార్డ్‌లో యాడాన్ URLలను నమోదు చేయండి. --yes డిఫాల్ట్‌లను అంగీకరిస్తుంది, --no-service కాన్ఫిగరేషన్‌ను మాత్రమే సేవ్ చేస్తుంది, --lang భాషను ఎంచుకుంటుంది. ఇప్పటికే ఉన్న టోకెన్లు, డౌన్‌లోడ్‌లు అలాగే ఉంటాయి.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup
```

```sh
npm run setup -- --no-service
npm start
```

## టీవీని కలపడం

state/status-url.txtలో ఉన్న చిరునామా తెరిచి భాష ఎంచుకుని Stremioలో ఇన్‌స్టాల్ చేయండి నొక్కండి, లేదా యాడ్‌ఆన్ చిరునామా ఇన్‌స్టాలేషన్ ఫీల్డ్‌లో అతికించండి. అదే ఖాతాలో టీవీ యాడ్‌ఆన్‌లను రిఫ్రెష్ చేయండి లేదా Stremio మళ్లీ తెరవండి. సినిమా లేదా ఎపిసోడ్‌కు స్థానిక కాష్ మూలం ఎంచుకోండి. అసలు మూలాలు వాటిని తెరిచే పరికరంలో పనిచేస్తాయి. ఖాతా యాడ్‌ఆన్‌లు ప్రతి 60 సెకన్లకు సమకాలీకరిస్తాయి.

## కాష్ మరియు ప్లేబ్యాక్

ప్లేయర్ మూసిన తర్వాత డౌన్‌లోడ్ కొనసాగుతుంది; సర్వర్ మళ్లీ ప్రారంభిస్తే తిరిగి సాగుతుంది. ఎంచుకున్న ఫైల్ మాత్రమే డౌన్‌లోడ్ అవుతుంది. డిఫాల్ట్ కాష్ 100 GiB, 10 GiB ఖాళీగా ఉంచబడుతుంది. అవసరమైనప్పుడు తక్కువ వాడిన పూర్తయిన టొరెంట్లు తొలగిస్తారు. ప్రారంభ సమయం peers, నెట్‌వర్క్‌పై ఆధారపడుతుంది. టీవీ వీడియో డీకోడ్ చేస్తుంది; transcoding లేదు. కంప్యూటర్ మేల్కొని అందుబాటులో ఉండాలి. IP మారితే baseUrl సరిచేసి యాడ్‌ఆన్ మళ్లీ ఇన్‌స్టాల్ చేయండి.

## గోప్యత మరియు లైసెన్స్

యాడ్‌ఆన్ URLలో యాక్సెస్ టోకెన్ ఉంది; దాన్ని వ్యక్తిగతంగా ఉంచండి. ఖాతా గుర్తింపు ప్రస్తుత స్థానిక Stremio ప్రొఫైల్ చదివి session keyని అధికారిక APIకి మాత్రమే పంపుతుంది; దాని కాపీ నిల్వ చేయదు. యాడ్‌ఆన్ చిరునామాలు వ్యక్తిగతంగా నిల్వ అవుతాయి. ప్రాజెక్ట్‌లో మీడియా కేటలాగ్ లేదా telemetry లేదు. BitTorrent peers కంప్యూటర్ IP చూడగలరు. మీకు అనుమతి ఉన్న కంటెంట్ వాడండి. MIT-PoU స్వయంచాలక వ్యవస్థలకు వాడుక నమోదు, మూలానికి గుర్తింపు తప్పనిసరి చేస్తుంది.
