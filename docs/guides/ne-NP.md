# Stremio Local Debrid — नेपाली

तपाईंको कम्प्युटरले Stremio एडअनका टोरेन्ट डाउनलोड र क्यास गर्छ, अनि स्थानीय सञ्जालबाट टिभीमा भिडियो पठाउँछ।

## यो किन बनाइयो

सुस्त टिभीलाई एकैसाथ टोरेन्ट डाउनलोड गर्न र भिडियो चलाउन गाह्रो हुन सक्छ। Stremio Local Debrid ले डाउनलोड र भण्डारण कम्प्युटरमा सार्छ। टिभीले घरको सञ्जालबाट HTTP भिडियो पाउँछ। सशुल्क क्लाउड debrid खाताबिना क्यास तपाईंको नियन्त्रणमा रहन्छ।

## यसले कसरी काम गर्छ

सर्भरले मिल्ने स्थापित एडअनको ठेगाना र सेटिङ जोगाएर स्ट्रिमका स्रोत माग्छ। टोरेन्ट ह्यास, magnet र .torrent लिङ्क स्थानीय क्यास स्रोत बन्छन्। स्रोत छान्दा कम्प्युटरमा डाउनलोड सुरु हुन्छ। एउटै फाइलले साझा क्यास प्रयोग गर्छ र ट्र्याकर एकत्र हुन्छन्। प्रत्यक्ष भिडियो लिङ्क र बाह्य सेवा रूपान्तरण हुँदैनन्।

## आवश्यकताहरू

Node.js 24 वा नयाँ, पर्याप्त खाली डिस्क र एउटै पहुँचयोग्य सञ्जालमा कम्प्युटर तथा टिभी चाहिन्छ। खाताको स्वचालित खोज macOS को Stremio 5 मा उपलब्ध छ। Linux र Windows मा एडअन सूची आफैं दिनुहोस्। Android TV, Google TV र Fire TV मुख्य लक्ष्य हुन्; अन्य क्लाइन्टलाई HTTPS र मिल्ने कोडेक चाहिन सक्छ।

## सर्भर स्थापना

macOS मा टिभीकै खाताबाट Stremio 5 मा प्रवेश गर्नुहोस्। Linux वा Windows मा npm run setup चलाउनुहोस्, कन्फिगर गरिएका एडअनका manifest URL config.json को sources मा थप्नुहोस् र autoDiscoverAddons लाई false बनाउनुहोस्। तीनै प्रणालीमा npm run install:service ले सर्भर सुरु गर्छ र प्रवेश गर्दा स्वतः चल्ने व्यवस्था गर्छ: LaunchAgent, systemd प्रयोगकर्ता सेवा वा Task Scheduler। Stremio बन्द रहन सक्छ। निजी config.json प्रकाशन नगर्नुहोस्।

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run install:service
```

```sh
npm run setup
npm start
```

## टिभी जोड्नुहोस्

state/status-url.txt मा सुरक्षित ठेगाना खोल्नुहोस्, भाषा छानेर Stremio मा स्थापना गर्नुहोस् थिच्नुहोस्, वा एडअन ठेगाना स्थापना क्षेत्रमा टाँस्नुहोस्। एउटै खाताबाट टिभीका एडअन ताजा गर्नुहोस् वा Stremio पुनः खोल्नुहोस्। चलचित्र वा एपिसोडमा स्थानीय क्यास स्रोत छान्नुहोस्। मूल स्रोत तिनलाई खोल्ने उपकरणमै चल्छन्। खाताका एडअन हरेक ६० सेकेन्डमा समक्रमण हुन्छन्।

## क्यास र प्लेब्याक

प्लेयर बन्द गरेपछि पनि डाउनलोड चल्छ र सर्भर पुनः सुरु भएपछि अधुरो डाउनलोड अघि बढ्छ। छानिएको फाइल मात्र डाउनलोड हुन्छ। पूर्वनिर्धारित क्यास 100 GiB हो र 10 GiB खाली राखिन्छ; ठाउँ चाहिँदा कम प्रयोग भएका पूरा टोरेन्ट हटाइन्छन्। सुरु हुने समय peers र सञ्जालमा निर्भर छ। टिभीले भिडियो डिकोड गर्छ; ट्रान्सकोडिङ छैन। कम्प्युटर जागा र पहुँचयोग्य राख्नुहोस्। IP फेरिए baseUrl सच्याएर एडअन पुनः स्थापना गर्नुहोस्।

## गोपनीयता र अनुमति

एडअन URL मा पहुँच टोकन हुन्छ; निजी राख्नुहोस्। खाताको खोजले स्थानीय Stremio प्रोफाइल पढेर सत्र कुञ्जी आधिकारिक API मा मात्र पठाउँछ, प्रतिलिपि राख्दैन। एडअन ठेगाना निजी रूपमा सुरक्षित हुन्छन्। परियोजनामा मिडिया सूची वा टेलिमेट्री छैन। BitTorrent peers ले कम्प्युटरको IP देख्न सक्छन्। पहुँचको अधिकार भएको सामग्री प्रयोग गर्नुहोस्। MIT-PoU ले स्वचालित प्रणालीलाई प्रयोगको अभिलेख र श्रेय दिन अनिवार्य गर्छ।
