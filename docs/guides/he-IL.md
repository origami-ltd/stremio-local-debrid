# Stremio Local Debrid — עברית

המחשב מוריד ושומר טורנטים מתוספי Stremio ומזרים את הווידאו לטלוויזיה דרך הרשת המקומית.

## למה הפרויקט קיים

טלוויזיה איטית עלולה להתקשות בהורדת טורנטים ובניגון וידאו במקביל. Stremio Local Debrid מעביר את ההורדה והאחסון למחשב. הטלוויזיה מקבלת זרם HTTP ברשת הביתית. המטמון בשליטתכם, ללא חשבון debrid בתשלום בענן.

## איך זה עובד

השרת מבקש מקורות מתוספים מותקנים תואמים ושומר על הכתובות וההגדרות שלהם. מזהי טורנט, קישורי magnet וקובצי .torrent הופכים למקורות מטמון מקומי. בחירת מקור מתחילה הורדה במחשב. קבצים כפולים חולקים מטמון ושרתי המעקב שלהם מאוחדים. קישורי וידאו ישירים ושירותים חיצוניים אינם מומרים.

## דרישות

נדרשים Node.js 24 ומעלה, מקום פנוי ומחשב וטלוויזיה באותה רשת נגישה. גילוי אוטומטי של תוספי החשבון נתמך ב־Stremio 5 ב־macOS. ב־Linux וב־Windows משתמשים ברשימת תוספים ידנית. Android TV, Google TV ו־Fire TV הם היעד העיקרי; לקוחות אחרים עשויים לדרוש HTTPS וקודקים תואמים.

## הגדרת השרת

הריצו npm run setup ליצירת config.json ולהגדרת ההפעלה ב-macOS, Linux או Windows. ב-macOS התחברו ל-Stremio 5 עם חשבון הטלוויזיה; ב-Linux/Windows הזינו באשף את כתובות התוספים. --yes מקבל את ברירות המחדל, --no-service שומר רק את ההגדרות והאפשרות --lang בוחר שפה. האסימונים וההורדות הקיימים נשמרים.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup
```

```sh
npm run setup -- --no-service
npm start
```

## חיבור הטלוויזיה

פתחו את הכתובת שב־state/status-url.txt, בחרו שפה ולחצו על התקנה ב־Stremio, או הדביקו את כתובת התוסף בשדה ההתקנה. רעננו תוספים או הפעילו מחדש את Stremio בטלוויזיה עם אותו חשבון. בחרו מקור מטמון מקומי לסרט או לפרק. המקורות המקוריים פועלים במכשיר שפותח אותם. תוספי החשבון מסתנכרנים כל 60 שניות.

## מטמון וניגון

ההורדה ממשיכה לאחר סגירת הנגן ומתחדשת אחרי הפעלה מחדש של השרת. רק הקובץ שנבחר יורד. ברירת המחדל היא מטמון של 100 GiB ושמירת 10 GiB פנויים; טורנטים שהושלמו ונעשה בהם פחות שימוש נמחקים כשצריך. תחילת הניגון תלויה בעמיתים וברשת. הטלוויזיה מפענחת את הווידאו; אין המרת קודקים. השאירו את המחשב ער ונגיש. אם כתובת ה־IP משתנה, עדכנו baseUrl והתקינו שוב את התוסף.

## פרטיות ורישיון

כתובת התוסף מכילה אסימון גישה; שמרו אותה פרטית. גילוי החשבון קורא את פרופיל Stremio המקומי ושולח את מפתח ההפעלה רק ל־API הרשמי, ללא שמירת עותק. כתובות התוספים נשמרות באופן פרטי. אין בפרויקט קטלוג מדיה או טלמטריה. עמיתי BitTorrent רואים את כתובת ה־IP של המחשב. השתמשו בתוכן שאתם רשאים לגשת אליו.
