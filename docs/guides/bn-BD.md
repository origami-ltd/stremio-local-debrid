# Stremio Local Debrid — বাংলা

আপনার কম্পিউটার Stremio অ্যাডঅন থেকে টরেন্ট ডাউনলোড ও ক্যাশ করে, তারপর স্থানীয় নেটওয়ার্কে টিভিতে ভিডিও পাঠায়।

## কেন এই প্রকল্প

ধীর টিভিতে একসঙ্গে টরেন্ট ডাউনলোড ও ভিডিও চালাতে সমস্যা হতে পারে। Stremio Local Debrid ডাউনলোড এবং সংরক্ষণের কাজ কম্পিউটারে সরিয়ে নেয়। টিভি ঘরের নেটওয়ার্কে HTTP ভিডিও পায়। অর্থের বিনিময়ে ক্লাউড debrid অ্যাকাউন্ট ছাড়াই ক্যাশ আপনার নিয়ন্ত্রণে থাকে।

## যেভাবে কাজ করে

সার্ভার উপযুক্ত ইনস্টল করা অ্যাডঅন থেকে তাদের কনফিগার করা ঠিকানা ও সেটিং অক্ষুণ্ণ রেখে উৎস চায়। টরেন্ট হ্যাশ, magnet ও .torrent লিংক স্থানীয় ক্যাশের উৎস হয়। উৎস বাছলে কম্পিউটারে ডাউনলোড শুরু হয়। একই ফাইলের ক্যাশ ভাগ করা হয় এবং ট্র্যাকার একত্র হয়। সরাসরি ভিডিও লিংক বা বাইরের সেবা রূপান্তর করা হয় না।

## প্রয়োজনীয়তা

Node.js 24 বা নতুন, পর্যাপ্ত ফাঁকা ডিস্ক এবং একই যোগাযোগযোগ্য নেটওয়ার্কে কম্পিউটার ও টিভি লাগবে। অ্যাকাউন্টের স্বয়ংক্রিয় শনাক্তকরণ macOS-এর Stremio 5 সমর্থন করে। Linux ও Windows-এ অ্যাডঅনের তালিকা নিজে দিন। Android TV, Google TV ও Fire TV প্রধান লক্ষ্য; অন্য ক্লায়েন্টের HTTPS ও উপযুক্ত কোডেক লাগতে পারে।

## সার্ভার তৈরি করুন

config.json তৈরি এবং macOS, Linux বা Windows-এ চালু হওয়া কনফিগার করতে npm run setup চালান। macOS-এ TV-এর অ্যাকাউন্ট দিয়ে Stremio 5-এ লগইন করুন; Linux/Windows-এ উইজার্ডে অ্যাডঅন URL লিখুন। --yes ডিফল্ট গ্রহণ করে, --no-service শুধু কনফিগারেশন সংরক্ষণ করে এবং --lang ভাষা বেছে নেয়। বিদ্যমান টোকেন ও ডাউনলোড বজায় থাকে।

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup
```

```sh
npm run setup -- --no-service
npm start
```

## টিভি সংযোগ

state/status-url.txt-এ রাখা ঠিকানা খুলুন, ভাষা বেছে Stremio-তে ইনস্টল করুন চাপুন, অথবা অ্যাডঅনের ঠিকানা ইনস্টলেশনের ঘরে পেস্ট করুন। একই অ্যাকাউন্টে টিভির অ্যাডঅন রিফ্রেশ করুন বা Stremio আবার খুলুন। সিনেমা বা পর্বে স্থানীয় ক্যাশের উৎস বাছুন। মূল উৎস যে যন্ত্রে খোলা হয় সেখানেই কাজ করে। অ্যাকাউন্টের অ্যাডঅন প্রতি ৬০ সেকেন্ডে সিঙ্ক হয়।

## ক্যাশ ও প্লেব্যাক

প্লেয়ার বন্ধ হলেও ডাউনলোড চলে, সার্ভার আবার চালু হলে অসম্পূর্ণ ডাউনলোড ফের শুরু হয়। শুধু নির্বাচিত ফাইল ডাউনলোড হয়। ডিফল্ট ক্যাশ 100 GiB, 10 GiB খালি রাখা হয়; দরকারে কম ব্যবহৃত সম্পূর্ণ টরেন্ট মুছে যায়। শুরু নির্ভর করে peers ও নেটওয়ার্কের ওপর। টিভি ভিডিও ডিকোড করে; ট্রান্সকোডিং নেই। কম্পিউটার জাগিয়ে ও যোগাযোগযোগ্য রাখুন। IP বদলালে baseUrl ঠিক করে অ্যাডঅন আবার ইনস্টল করুন।

## গোপনীয়তা ও লাইসেন্স

অ্যাডঅনের URL-এ অ্যাক্সেস টোকেন থাকে; এটি ব্যক্তিগত রাখুন। অ্যাকাউন্ট শনাক্তকরণ বর্তমান স্থানীয় Stremio প্রোফাইল পড়ে এবং সেশন কী শুধু সরকারি API-তে পাঠায়, তার কপি জমায় না। অ্যাডঅনের ঠিকানা ব্যক্তিগতভাবে সংরক্ষিত হয়। প্রকল্পে মিডিয়া ক্যাটালগ বা টেলিমেট্রি নেই। BitTorrent peers কম্পিউটারের IP দেখতে পায়। আপনার ব্যবহারের অধিকার আছে এমন কনটেন্ট ব্যবহার করুন। MIT-PoU স্বয়ংক্রিয় সিস্টেমের জন্য ব্যবহার নথিভুক্ত করা ও কৃতিত্ব দেওয়া বাধ্যতামূলক করে।
