# Stremio Local Debrid — Беларуская

Камп’ютар спампоўвае і захоўвае торэнты з вашых дадаткаў Stremio ды перадае відэа на тэлевізар праз лакальную сетку.

## Навошта існуе праект

Павольнаму тэлевізару цяжка адначасова шукаць піраў, спампоўваць часткі торэнта і прайграваць відэа. Stremio Local Debrid пераносіць спампоўванне і захоўванне на камп’ютар. Тэлевізар атрымлівае HTTP-відэа праз хатнюю сетку. Вы кіруеце ўласным кэшам без платнага воблачнага debrid-акаўнта.

## Як гэта працуе

Сервер запытвае крыніцы ва ўсталяваных дадаткаў, захоўваючы іх налады. Хэшы, magnet-спасылкі і спасылкі .torrent становяцца крыніцамі лакальнага кэша. Выбар запускае спампоўванне на камп’ютары і перадачу абранага файла тэлевізару. Дублікаты маюць агульны кэш і аб’яднаныя трэкеры. Прамыя відэаспасылкі і вонкавыя сэрвісы не пераўтвараюцца.

## Патрабаванні

Патрэбныя Node.js 24 ці навейшы, вольнае месца і камп’ютар з тэлевізарам, даступныя адзін аднаму ў адной сетцы. Аўтаматычнае выяўленне акаўнта падтрымлівае Stremio 5 для macOS. Linux і Windows выкарыстоўваюць ручны спіс дадаткаў. Асноўныя прылады: Android TV, Google TV і Fire TV; іншым кліентам могуць спатрэбіцца HTTPS і сумяшчальныя кодэкі.

## Усталяванне сервера

У macOS увайдзіце ў Stremio 5 з акаўнтам тэлевізара. У Linux ці Windows выканайце npm run setup, дадайце наладжаныя URL маніфестаў у sources у config.json і задайце autoDiscoverAddons: false. На ўсіх трох сістэмах выканайце npm run install:service. Сервер запускаецца і аўтаматычна стартавае пры ўваходзе праз LaunchAgent, systemd ці Планавальнік задач. Stremio можна закрыць.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run install:service
```

```sh
npm run setup
npm start
```

## Падключэнне тэлевізара

Адкрыйце адрас з state/status-url.txt, абярыце мову і Усталяваць у Stremio ці ўстаўце адрас у поле ўсталявання. На тэлевізары выкарыстоўвайце той самы акаўнт і абнавіце дадаткі ці перазапусціце Stremio. Для фільма ці серыі абярыце Лакальны кэш. Зыходныя крыніцы па-ранейшаму выкарыстоўваюць прыладу, якая іх адкрывае. Спіс акаўнта сінхранізуецца кожныя 60 секунд.

## Кэш і прайграванне

Спампоўванні працягваюцца пасля закрыцця прайгравальніка і аднаўляюцца пасля перазапуску сервера. Спампоўваецца толькі абраны файл. Стандартна кэш складае 100 GiB, рэзерв вольнага месца — 10 GiB. Гатовыя рэдка выкарыстаныя торэнты выдаляюцца пры патрэбе. Пачатак залежыць ад піраў і сеткі. Перакадавання няма: відэа дэкадуе тэлевізар. Трымайце камп’ютар актыўным і даступным. Пры змене IP абнавіце baseUrl і пераўсталюйце дадатак.
