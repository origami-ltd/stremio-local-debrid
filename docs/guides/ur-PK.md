# Stremio Local Debrid — اردو

آپ کا کمپیوٹر Stremio کے ایڈ آنز سے ٹورنٹ ڈاؤن لوڈ اور محفوظ کرتا ہے، پھر مقامی نیٹ ورک پر ٹی وی کو ویڈیو بھیجتا ہے۔

## یہ کیوں بنایا گیا

سست ٹی وی کو بیک وقت ٹورنٹ ڈاؤن لوڈ کرنے اور ویڈیو چلانے میں مشکل ہو سکتی ہے۔ Stremio Local Debrid ڈاؤن لوڈ اور ذخیرہ کمپیوٹر پر منتقل کرتا ہے۔ ٹی وی گھریلو نیٹ ورک پر HTTP ویڈیو وصول کرتا ہے۔ ادا شدہ کلاؤڈ debrid اکاؤنٹ کے بغیر کیش آپ کے اختیار میں رہتا ہے۔

## یہ کیسے کام کرتا ہے

سرور مطابقت رکھنے والے نصب شدہ ایڈ آنز سے ان کے پتے اور ترتیبات برقرار رکھتے ہوئے ذرائع لیتا ہے۔ ٹورنٹ ہیش، magnet روابط اور .torrent فائلیں مقامی کیش کے ذرائع بنتی ہیں۔ ذریعہ منتخب کرنے پر کمپیوٹر ڈاؤن لوڈ شروع کرتا ہے۔ یکساں فائلوں کا کیش مشترک ہوتا ہے اور ٹریکرز ملا دیے جاتے ہیں۔ براہ راست ویڈیو روابط اور بیرونی خدمات تبدیل نہیں ہوتیں۔

## ضروریات

Node.js 24 یا جدید تر، کافی خالی جگہ اور ایک ہی قابل رسائی نیٹ ورک پر کمپیوٹر اور ٹی وی درکار ہیں۔ اکاؤنٹ کی خودکار دریافت macOS پر Stremio 5 میں دستیاب ہے۔ Linux اور Windows پر ایڈ آنز کی فہرست دستی طور پر دیں۔ Android TV، Google TV اور Fire TV بنیادی ہدف ہیں؛ دوسرے کلائنٹس کو HTTPS اور موافق کوڈیکس درکار ہو سکتے ہیں۔

## سرور ترتیب دیں

macOS پر ٹی وی والے اکاؤنٹ سے Stremio 5 میں داخل ہوں۔ Linux یا Windows پر npm run setup چلائیں، ترتیب شدہ ایڈ آنز کے manifest پتے config.json کے sources میں ڈالیں اور autoDiscoverAddons کو false کریں۔ تینوں نظاموں پر npm run install:service سرور شروع کرتا اور لاگ ان پر خودکار آغاز درج کرتا ہے، بالترتیب LaunchAgent، systemd صارف سروس اور Task Scheduler کے ذریعے۔ Stremio بند رہ سکتا ہے۔ نجی config.json شائع نہ کریں۔

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run install:service
```

```sh
npm run setup
npm start
```

## ٹی وی جوڑیں

state/status-url.txt میں محفوظ پتہ کھولیں، زبان چنیں اور Stremio میں نصب کریں پر کلک کریں، یا ایڈ آن پتہ تنصیب کے خانے میں ڈالیں۔ اسی اکاؤنٹ سے ٹی وی پر ایڈ آنز تازہ کریں یا Stremio دوبارہ کھولیں۔ فلم یا قسط کے لیے مقامی کیش کا ذریعہ چنیں۔ اصل ذرائع انہیں کھولنے والے آلے پر چلتے ہیں۔ اکاؤنٹ کے ایڈ آنز ہر 60 سیکنڈ میں ہم آہنگ ہوتے ہیں۔

## کیش اور پلے بیک

پلیئر بند کرنے کے بعد ڈاؤن لوڈ جاری رہتا ہے اور سرور دوبارہ شروع ہونے پر بحال ہوتا ہے۔ صرف منتخب فائل ڈاؤن لوڈ ہوتی ہے۔ پہلے سے مقرر کیش 100 GiB ہے اور 10 GiB خالی رکھی جاتی ہے؛ ضرورت پر کم استعمال شدہ مکمل ٹورنٹ حذف ہوتے ہیں۔ آغاز کا وقت peers اور نیٹ ورک پر منحصر ہے۔ ٹی وی ویڈیو ڈی کوڈ کرتا ہے؛ ٹرانس کوڈنگ نہیں ہوتی۔ کمپیوٹر بیدار اور قابل رسائی رکھیں۔ IP بدلے تو baseUrl درست کرکے ایڈ آن دوبارہ نصب کریں۔

## رازداری اور لائسنس

ایڈ آن کے پتے میں رسائی ٹوکن ہے؛ اسے نجی رکھیں۔ اکاؤنٹ کی دریافت موجودہ مقامی Stremio پروفائل پڑھتی اور سیشن کلید صرف سرکاری API کو بھیجتی ہے، اس کی نقل محفوظ نہیں کرتی۔ ایڈ آن پتے نجی محفوظ ہوتے ہیں۔ منصوبے میں میڈیا کیٹلاگ یا ٹیلی میٹری نہیں۔ BitTorrent peers کمپیوٹر کا IP دیکھ سکتے ہیں۔ صرف وہ مواد استعمال کریں جس تک رسائی کا حق ہو۔ MIT-PoU خودکار نظاموں کے لیے استعمال کا اندراج اور ماخذ کا اعتراف لازم کرتا ہے۔
