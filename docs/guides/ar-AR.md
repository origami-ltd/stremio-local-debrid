# Stremio Local Debrid — العربية

ينزّل حاسوبك ملفات التورنت من إضافات Stremio ويخزّنها مؤقتًا، ثم يبث الفيديو إلى التلفاز عبر الشبكة المحلية.

## لماذا هذا المشروع؟

قد يصعب على التلفاز البطيء تنزيل التورنت وتشغيل الفيديو في الوقت نفسه. ينقل Stremio Local Debrid التنزيل والتخزين إلى الحاسوب، ويتلقى التلفاز بث HTTP عبر شبكة المنزل. تتحكم في الذاكرة المؤقتة دون حساب debrid سحابي مدفوع.

## كيف يعمل؟

يطلب الخادم المصادر من الإضافات المتوافقة المثبتة، مع الحفاظ على عناوينها وإعداداتها. يحوّل بصمات التورنت وروابط magnet وملفات .torrent إلى مصادر ذاكرة محلية. اختيار مصدر يبدأ التنزيل على الحاسوب. تشترك الملفات المكررة في التخزين وتُدمج خوادم التتبع. لا تُحوّل روابط الفيديو المباشرة أو الخدمات الخارجية.

## المتطلبات

يلزم Node.js 24 أو أحدث ومساحة قرص كافية وحاسوب وتلفاز يمكنهما الاتصال عبر الشبكة نفسها. اكتشاف إضافات الحساب تلقائيًا يدعم Stremio 5 على macOS. يستخدم Linux وWindows قائمة إضافات يدوية. أجهزة Android TV وGoogle TV وFire TV هي الوجهة الأساسية؛ قد تحتاج الأجهزة الأخرى إلى HTTPS وترميزات متوافقة.

## إعداد الخادم

شغّل npm run setup لإنشاء config.json وضبط بدء التشغيل على macOS أو Linux أو Windows. على macOS، سجّل الدخول إلى Stremio 5 بحساب التلفزيون؛ على Linux/Windows، أدخل عناوين الإضافات في المعالج. يقبل --yes القيم الافتراضية، ويحفظ --no-service الإعدادات فقط، ويحدد --lang اللغة. تُحفظ الرموز والتنزيلات الموجودة.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup
```

```sh
npm run setup -- --no-service
npm start
```

## ربط التلفاز

افتح العنوان المحفوظ في state/status-url.txt، واختر اللغة ثم التثبيت في Stremio، أو الصق عنوان الإضافة في حقل التثبيت. حدّث الإضافات أو أعد تشغيل Stremio على التلفاز بالحساب نفسه، ثم اختر مصدر ذاكرة محلية لفيلم أو حلقة. تستخدم المصادر الأصلية الجهاز الذي يفتحها. تتزامن إضافات الحساب كل 60 ثانية.

## التخزين والتشغيل

يستمر التنزيل بعد إغلاق المشغّل ويُستأنف بعد إعادة تشغيل الخادم. يُنزّل الملف المختار فقط. الحد الافتراضي 100 GiB مع إبقاء 10 GiB فارغة؛ تُحذف ملفات التورنت المكتملة الأقل استخدامًا عند الحاجة. تعتمد بداية التشغيل على الأقران والشبكة. يفك التلفاز ترميز الفيديو؛ لا توجد إعادة ترميز. أبقِ الحاسوب مستيقظًا ومتصلًا. إذا تغيّر عنوان IP، حدّث baseUrl وأعد تثبيت الإضافة.

## الخصوصية والترخيص

يتضمن عنوان الإضافة رمز وصول؛ احتفظ به سريًا. يقرأ اكتشاف الحساب ملف Stremio المحلي، ويرسل مفتاح الجلسة إلى واجهة Stremio الرسمية فقط دون حفظ نسخة منه. تُحفظ عناوين الإضافات بشكل خاص. لا يتضمن المشروع فهرس وسائط أو قياسًا عن بُعد. يرى أقران BitTorrent عنوان IP للحاسوب. استخدم محتوى يحق لك الوصول إليه. يضيف ترخيص MIT-PoU متطلبات تسجيل الاستخدام ونسب الفضل للأنظمة الآلية.
