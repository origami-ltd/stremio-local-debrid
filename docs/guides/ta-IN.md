# Stremio Local Debrid — தமிழ்

உங்கள் கணினி Stremio துணைநிரல்களின் டொரண்டுகளைப் பதிவிறக்கிச் சேமித்து, உள்ளூர் வலையமைப்பு வழியாகத் தொலைக்காட்சிக்கு வீடியோ அனுப்புகிறது.

## இது ஏன் உருவானது

மெதுவான தொலைக்காட்சி ஒரே நேரத்தில் டொரண்டைப் பதிவிறக்கவும் வீடியோ இயக்கவும் சிரமப்படலாம். Stremio Local Debrid பதிவிறக்கத்தையும் சேமிப்பையும் கணினிக்கு மாற்றுகிறது. தொலைக்காட்சி வீட்டு வலையமைப்பில் HTTP வீடியோ பெறுகிறது. கட்டண மேக debrid கணக்கு இல்லாமலே சேமிப்பு உங்கள் கட்டுப்பாட்டில் இருக்கும்.

## செயல்படும் விதம்

சேவையகம் இணக்கமான நிறுவப்பட்ட துணைநிரல்களின் முகவரிகளையும் அமைப்புகளையும் பாதுகாத்து வீடியோ மூலங்களைக் கேட்கிறது. டொரண்ட் ஹாஷ்கள், magnet மற்றும் .torrent இணைப்புகள் உள்ளூர் சேமிப்பு மூலங்களாகின்றன. ஒன்றைத் தேர்ந்தெடுத்தால் கணினியில் பதிவிறக்கம் தொடங்கும். ஒரே கோப்புக்குப் பொதுவான சேமிப்பு பயன்படும்; tracker-கள் இணைக்கப்படும். நேரடி வீடியோ இணைப்புகளும் வெளிச் சேவைகளும் மாற்றப்படாது.

## தேவைகள்

Node.js 24 அல்லது புதியது, போதுமான காலி வட்டு இடம், ஒரே அணுகக்கூடிய வலையமைப்பில் கணினியும் தொலைக்காட்சியும் தேவை. கணக்கின் தானியங்கி கண்டறிதல் macOS-இல் Stremio 5-ஐ ஆதரிக்கிறது. Linux மற்றும் Windows-இல் துணைநிரல் பட்டியலைக் கைமுறையாகத் தரவும். Android TV, Google TV, Fire TV முதன்மை இலக்குகள்; பிற செயலிகளுக்கு HTTPS மற்றும் இணக்கமான codec தேவைப்படலாம்.

## சேவையகத்தை அமைத்தல்

config.json உருவாக்கி macOS, Linux அல்லது Windows-இல் தொடக்கத்தை அமைக்க npm run setup இயக்கவும். macOS-இல் TV கணக்குடன் Stremio 5-இல் உள்நுழையவும்; Linux/Windows-இல் வழிகாட்டியில் துணை நிரல் URL-களை உள்ளிடவும். --yes இயல்புநிலைகளை ஏற்கும், --no-service அமைப்பை மட்டும் சேமிக்கும், --lang மொழியைத் தேர்ந்தெடுக்கும். ஏற்கெனவே உள்ள டோக்கன்களும் பதிவிறக்கங்களும் பாதுகாக்கப்படும்.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup
```

```sh
npm run setup -- --no-service
npm start
```

## தொலைக்காட்சியை இணைத்தல்

state/status-url.txt-இல் சேமித்த முகவரியைத் திறந்து, மொழியைத் தேர்ந்தெடுத்து Stremio-வில் நிறுவு அழுத்தவும்; அல்லது துணைநிரல் முகவரியை நிறுவல் புலத்தில் ஒட்டவும். அதே கணக்கில் தொலைக்காட்சியின் துணைநிரல்களைப் புதுப்பிக்கவும் அல்லது Stremio-வை மீண்டும் திறக்கவும். திரைப்படம் அல்லது அத்தியாயத்திற்கு உள்ளூர் சேமிப்பு மூலத்தைத் தேர்ந்தெடுக்கவும். அசல் மூலங்கள் அவற்றைத் திறக்கும் சாதனத்திலேயே இயங்கும். கணக்கின் துணைநிரல்கள் ஒவ்வொரு 60 வினாடிக்கும் ஒத்திசைகின்றன.

## சேமிப்பும் இயக்கமும்

வீடியோ இயக்கியை மூடிய பின்னும் பதிவிறக்கம் தொடரும்; சேவையகத்தை மீண்டும் தொடங்கினால் மீளும். தேர்ந்தெடுத்த கோப்பு மட்டுமே பதிவிறங்கும். இயல்புநிலை சேமிப்பு 100 GiB; 10 GiB காலியாக வைக்கப்படும். இடம் தேவைப்பட்டால் குறைவாகப் பயன்படுத்திய முழுமையான டொரண்டுகள் நீக்கப்படும். தொடக்கம் peers மற்றும் வலையமைப்பைப் பொறுத்தது. தொலைக்காட்சியே வீடியோவை decode செய்கிறது; transcoding இல்லை. கணினியை விழிப்பிலும் அணுகக்கூடிய நிலையிலும் வைக்கவும். IP மாறினால் baseUrl-ஐத் திருத்தி துணைநிரலை மீண்டும் நிறுவவும்.

## தனியுரிமையும் உரிமமும்

துணைநிரல் URL-இல் அணுகல் token உள்ளது; தனிப்பட்டதாக வைக்கவும். கணக்கைக் கண்டறிதல் தற்போதைய உள்ளூர் Stremio சுயவிவரத்தைப் படித்து session key-ஐ அதிகாரப்பூர்வ API-க்கு மட்டுமே அனுப்பும்; அதன் நகலைச் சேமிக்காது. துணைநிரல் முகவரிகள் தனிப்பட்ட முறையில் சேமிக்கப்படும். ஊடகப் பட்டியலோ telemetry-யோ இல்லை. BitTorrent peers கணினியின் IP-ஐக் காணலாம். உங்களுக்கு அணுக உரிமையுள்ள உள்ளடக்கத்தைப் பயன்படுத்தவும். MIT-PoU தானியங்கி அமைப்புகளுக்கு பயன்பாட்டைப் பதிவு செய்வதையும் உரியவர்களுக்கு நன்றி தெரிவிப்பதையும் கட்டாயமாக்குகிறது.
