# Stremio Local Debrid — Українська

Комп’ютер завантажує й зберігає торенти з ваших доповнень Stremio та передає відео на телевізор локальною мережею.

## Навіщо існує проєкт

Повільному телевізору важко одночасно шукати пірів, завантажувати частини торента й відтворювати відео. Stremio Local Debrid переносить завантаження та зберігання на комп’ютер. Телевізор отримує HTTP-відео домашньою мережею. Ви керуєте власним кешем без платного хмарного debrid-акаунта.

## Як це працює

Сервер запитує джерела у встановлених доповнень, зберігаючи їхні налаштування. Хеші, magnet-посилання й посилання .torrent стають джерелами локального кешу. Вибір запускає завантаження на комп’ютері та передавання вибраного файла телевізору. Дублікати мають спільний кеш і об’єднані трекери. Прямі відеопосилання й зовнішні сервіси не перетворюються.

## Вимоги

Потрібні Node.js 24 або новіший, вільне місце та комп’ютер і телевізор, доступні один одному в одній мережі. Автоматичне виявлення акаунта працює зі Stremio 5 для macOS. Linux і Windows використовують ручний список доповнень. Основні пристрої: Android TV, Google TV і Fire TV; іншим клієнтам можуть знадобитися HTTPS та сумісні кодеки.

## Встановлення сервера

Запустіть npm run setup, щоб створити config.json і налаштувати запуск у macOS, Linux або Windows. У macOS увійдіть у Stremio 5 з обліковим записом телевізора; у Linux/Windows введіть URL додатків у майстрі. --yes приймає типові значення, --no-service лише зберігає конфігурацію, а --lang вибирає мову. Наявні токени та завантаження зберігаються.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup
```

```sh
npm run setup -- --no-service
npm start
```

## Підключення телевізора

Відкрийте адресу зі state/status-url.txt, виберіть мову й Встановити в Stremio або вставте адресу доповнення в поле встановлення. На телевізорі використовуйте той самий акаунт, оновіть доповнення або перезапустіть Stremio. Для фільму чи серії виберіть Локальний кеш. Початкові джерела й надалі використовують пристрій, що їх відкриває. Список акаунта синхронізується кожні 60 секунд.

## Кеш і відтворення

Завантаження триває після закриття програвача та відновлюється після перезапуску сервера. Завантажується лише вибраний файл. Типово кеш має 100 GiB, резерв вільного місця — 10 GiB. Завершені рідко використовувані торенти видаляються за потреби. Початок залежить від пірів і мережі. Транскодування немає: відео декодує телевізор. Тримайте комп’ютер активним і доступним. Після зміни IP оновіть baseUrl і перевстановіть доповнення.

## Приватність і ліцензія

Адреса містить приватний токен: не публікуйте його у зверненнях чи знімках екрана. macOS читає наявний профіль і передає ключ сесії лише офіційному API Stremio, не зберігаючи копії. Налаштовані адреси зберігаються приватно. Каталогу медіа й телеметрії немає. Піри можуть бачити IP комп’ютера. Використовуйте вміст, до якого маєте право доступу.
