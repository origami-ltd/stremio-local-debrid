# Stremio Local Debrid — Русский

Компьютер скачивает и сохраняет торренты из ваших дополнений Stremio и передаёт видео на телевизор по локальной сети.

## Зачем нужен проект

Медленному телевизору сложно одновременно искать пиров, скачивать части торрента и воспроизводить видео. Stremio Local Debrid переносит скачивание и хранение на компьютер. Телевизор получает HTTP-видео по домашней сети. Вы управляете своим кэшем без платного облачного debrid-аккаунта.

## Как это работает

Сервер запрашивает источники у установленных дополнений, сохраняя их настройки. Хэши торрентов, magnet-ссылки и ссылки .torrent становятся источниками локального кэша. Выбор источника запускает скачивание на компьютере и передачу выбранного файла телевизору. Дубликаты используют общий кэш и объединённые трекеры. Прямые видеоссылки и внешние сервисы не преобразуются.

## Требования

Нужны Node.js 24 или новее, свободное место и компьютер с телевизором, доступные друг другу в одной сети. Автоматическое обнаружение аккаунта работает со Stremio 5 для macOS. Linux и Windows используют ручной список дополнений. Основные устройства: Android TV, Google TV и Fire TV; другим клиентам могут потребоваться HTTPS и совместимые кодеки.

## Установка сервера

В macOS войдите в Stremio 5 с аккаунтом телевизора. В Linux или Windows выполните npm run setup, добавьте настроенные URL манифестов в sources файла config.json и задайте autoDiscoverAddons: false. Во всех трёх системах выполните npm run install:service. Сервер запускается и регистрирует автоматический запуск при входе через LaunchAgent, systemd или Планировщик заданий. Stremio можно закрыть.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run install:service
```

```sh
npm run setup
npm start
```

## Подключение телевизора

Откройте адрес из state/status-url.txt, выберите язык и нажмите Установить в Stremio либо вставьте адрес дополнения в поле установки. На телевизоре используйте тот же аккаунт, обновите дополнения или перезапустите Stremio. Для фильма или серии выберите Локальный кэш. Исходные источники по-прежнему используют открывающее их устройство. Список аккаунта синхронизируется каждые 60 секунд.

## Кэш и воспроизведение

Скачивание продолжается после закрытия плеера и возобновляется после перезапуска сервера. Загружается только выбранный файл. По умолчанию кэш составляет 100 GiB, резерв свободного места — 10 GiB. Завершённые редко используемые торренты удаляются при нехватке места. Первый запуск зависит от пиров и сети. Транскодирования нет: видео декодирует телевизор. Не усыпляйте компьютер. При смене IP обновите baseUrl и переустановите дополнение.

## Конфиденциальность и лицензия

Адрес содержит личный токен доступа: не публикуйте его в обращениях или снимках экрана. macOS читает существующий профиль и отправляет ключ сессии только официальному API Stremio, не сохраняя копию. Настроенные адреса хранятся приватно. Каталога медиа и телеметрии нет. Пиры могут видеть IP компьютера. Используйте доступный вам по праву контент.
