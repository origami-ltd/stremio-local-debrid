# Stremio Local Debrid — فارسی

رایانهٔ شما تورنت‌های افزونه‌های Stremio را دانلود و ذخیره می‌کند و ویدئو را از شبکهٔ محلی به تلویزیون می‌فرستد.

## چرا این پروژه؟

تلویزیون کند ممکن است نتواند هم‌زمان تورنت دانلود کند و ویدئو پخش کند. Stremio Local Debrid دانلود و ذخیره‌سازی را به رایانه منتقل می‌کند. تلویزیون جریان HTTP را از شبکهٔ خانه می‌گیرد. بدون حساب پولی debrid ابری، کنترل حافظهٔ موقت دست شماست.

## روش کار

سرور از افزونه‌های سازگار نصب‌شده با حفظ نشانی و تنظیمات آن‌ها منابع پخش می‌گیرد. هش تورنت، پیوند magnet و فایل .torrent به منابع حافظهٔ محلی تبدیل می‌شوند. انتخاب منبع دانلود را روی رایانه آغاز می‌کند. فایل‌های تکراری حافظهٔ مشترک دارند و ردیاب‌هایشان ادغام می‌شوند. پیوند مستقیم ویدئو و خدمات خارجی تبدیل نمی‌شوند.

## نیازمندی‌ها

Node.js 24 یا جدیدتر، فضای خالی کافی و رایانه و تلویزیون در یک شبکهٔ قابل‌دسترسی لازم است. شناسایی خودکار حساب از Stremio 5 در macOS پشتیبانی می‌کند. Linux و Windows فهرست دستی افزونه دارند. Android TV، Google TV و Fire TV هدف اصلی‌اند؛ دیگر دستگاه‌ها ممکن است به HTTPS و کدک سازگار نیاز داشته باشند.

## راه‌اندازی سرور

برای ساخت config.json و تنظیم اجرای خودکار در macOS، Linux یا Windows، فرمان npm run setup را اجرا کنید. در macOS با حساب تلویزیون وارد Stremio 5 شوید؛ در Linux/Windows نشانی افزونه‌ها را در راهنما وارد کنید. --yes پیش‌فرض‌ها را می‌پذیرد، --no-service فقط پیکربندی را ذخیره می‌کند و --lang زبان را انتخاب می‌کند. توکن‌ها و دانلودهای موجود حفظ می‌شوند.

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup
```

```sh
npm run setup -- --no-service
npm start
```

## اتصال تلویزیون

نشانی state/status-url.txt را باز کنید، زبان را انتخاب و نصب در Stremio را بزنید، یا نشانی افزونه را در بخش نصب وارد کنید. افزونه‌ها را به‌روز کنید یا Stremio تلویزیون را با همان حساب دوباره باز کنید. برای فیلم یا قسمت، منبع حافظهٔ محلی را انتخاب کنید. منابع اصلی روی دستگاه بازکننده کار می‌کنند. افزونه‌های حساب هر ۶۰ ثانیه همگام می‌شوند.

## حافظه و پخش

دانلود پس از بستن پخش‌کننده ادامه دارد و پس از راه‌اندازی دوباره از سر گرفته می‌شود. فقط فایل انتخاب‌شده دانلود می‌شود. پیش‌فرض حافظه 100 GiB و فضای آزاد محفوظ 10 GiB است؛ تورنت‌های کامل کم‌استفاده در صورت نیاز حذف می‌شوند. شروع پخش به همتاها و شبکه بستگی دارد. تلویزیون ویدئو را رمزگشایی می‌کند؛ تبدیل کدک انجام نمی‌شود. رایانه را بیدار و متصل نگه دارید. با تغییر IP، baseUrl را اصلاح و افزونه را دوباره نصب کنید.

## حریم خصوصی و مجوز

نشانی افزونه توکن دسترسی دارد؛ آن را خصوصی نگه دارید. شناسایی حساب، نمایهٔ محلی Stremio را می‌خواند و کلید نشست را فقط به API رسمی می‌فرستد، بدون ذخیرهٔ نسخهٔ آن. نشانی افزونه‌ها خصوصی ذخیره می‌شود. پروژه فهرست رسانه و تله‌متری ندارد. همتاهای BitTorrent می‌توانند IP رایانه را ببینند. از محتوای مجاز استفاده کنید.
