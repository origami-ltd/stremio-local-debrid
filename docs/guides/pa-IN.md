# Stremio Local Debrid — ਪੰਜਾਬੀ

ਤੁਹਾਡਾ ਕੰਪਿਊਟਰ Stremio ਐਡਆਨ ਦੇ ਟੋਰੈਂਟ ਡਾਊਨਲੋਡ ਅਤੇ ਕੈਸ਼ ਕਰਦਾ ਹੈ, ਫਿਰ ਸਥਾਨਕ ਨੈੱਟਵਰਕ ਰਾਹੀਂ ਟੀਵੀ ਨੂੰ ਵੀਡੀਓ ਭੇਜਦਾ ਹੈ।

## ਇਹ ਕਿਉਂ ਬਣਾਇਆ

ਹੌਲੀ ਟੀਵੀ ਨੂੰ ਇੱਕੋ ਸਮੇਂ ਟੋਰੈਂਟ ਡਾਊਨਲੋਡ ਕਰਨ ਅਤੇ ਵੀਡੀਓ ਚਲਾਉਣ ਵਿੱਚ ਮੁਸ਼ਕਲ ਹੋ ਸਕਦੀ ਹੈ। Stremio Local Debrid ਡਾਊਨਲੋਡ ਅਤੇ ਸਟੋਰੇਜ ਕੰਪਿਊਟਰ ਉੱਤੇ ਲੈ ਜਾਂਦਾ ਹੈ। ਟੀਵੀ ਘਰ ਦੇ ਨੈੱਟਵਰਕ ਉੱਤੇ HTTP ਵੀਡੀਓ ਲੈਂਦੀ ਹੈ। ਅਦਾਇਗੀ ਵਾਲੇ ਕਲਾਊਡ debrid ਖਾਤੇ ਤੋਂ ਬਿਨਾਂ ਕੈਸ਼ ਤੁਹਾਡੇ ਕੰਟਰੋਲ ਵਿੱਚ ਰਹਿੰਦਾ ਹੈ।

## ਇਹ ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ

ਸਰਵਰ ਅਨੁਕੂਲ ਇੰਸਟਾਲ ਕੀਤੇ ਐਡਆਨ ਤੋਂ ਉਹਨਾਂ ਦੇ ਸੈੱਟ ਕੀਤੇ ਪਤੇ ਅਤੇ ਸੈਟਿੰਗਾਂ ਬਰਕਰਾਰ ਰੱਖ ਕੇ ਸਰੋਤ ਲੈਂਦਾ ਹੈ। ਟੋਰੈਂਟ ਹੈਸ਼, magnet ਅਤੇ .torrent ਲਿੰਕ ਸਥਾਨਕ ਕੈਸ਼ ਸਰੋਤ ਬਣਦੇ ਹਨ। ਸਰੋਤ ਚੁਣਨ ਉੱਤੇ ਕੰਪਿਊਟਰ ਡਾਊਨਲੋਡ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ। ਇੱਕੋ ਫਾਈਲ ਦਾ ਕੈਸ਼ ਸਾਂਝਾ ਹੁੰਦਾ ਹੈ ਅਤੇ ਟ੍ਰੈਕਰ ਜੋੜੇ ਜਾਂਦੇ ਹਨ। ਸਿੱਧੇ ਵੀਡੀਓ ਲਿੰਕ ਅਤੇ ਬਾਹਰੀ ਸੇਵਾਵਾਂ ਬਦਲੀਆਂ ਨਹੀਂ ਜਾਂਦੀਆਂ।

## ਲੋੜਾਂ

Node.js 24 ਜਾਂ ਨਵਾਂ, ਕਾਫ਼ੀ ਖਾਲੀ ਡਿਸਕ ਅਤੇ ਇੱਕੋ ਪਹੁੰਚਯੋਗ ਨੈੱਟਵਰਕ ਉੱਤੇ ਕੰਪਿਊਟਰ ਤੇ ਟੀਵੀ ਚਾਹੀਦੇ ਹਨ। ਖਾਤੇ ਦੀ ਆਟੋਮੈਟਿਕ ਖੋਜ macOS ਦੇ Stremio 5 ਵਿੱਚ ਹੈ। Linux ਅਤੇ Windows ਉੱਤੇ ਐਡਆਨ ਸੂਚੀ ਹੱਥੀਂ ਦਿਓ। Android TV, Google TV ਅਤੇ Fire TV ਮੁੱਖ ਟੀਚੇ ਹਨ; ਹੋਰ ਕਲਾਇੰਟਾਂ ਨੂੰ HTTPS ਅਤੇ ਅਨੁਕੂਲ ਕੋਡੈਕ ਚਾਹੀਦੇ ਹੋ ਸਕਦੇ ਹਨ।

## ਸਰਵਰ ਸੈੱਟ ਕਰੋ

config.json ਬਣਾਉਣ ਅਤੇ macOS, Linux ਜਾਂ Windows ਉੱਤੇ ਸ਼ੁਰੂਆਤ ਸੰਰਚਿਤ ਕਰਨ ਲਈ npm run setup ਚਲਾਓ। macOS ਉੱਤੇ TV ਦੇ ਖਾਤੇ ਨਾਲ Stremio 5 ਵਿੱਚ ਲਾਗਇਨ ਕਰੋ; Linux/Windows ਉੱਤੇ ਵਿਜ਼ਾਰਡ ਵਿੱਚ ਐਡਆਨ URL ਦਰਜ ਕਰੋ। --yes ਮੂਲ ਮੁੱਲ ਮੰਨਦਾ ਹੈ, --no-service ਸਿਰਫ਼ ਸੰਰਚਨਾ ਸੰਭਾਲਦਾ ਹੈ ਅਤੇ --lang ਭਾਸ਼ਾ ਚੁਣਦਾ ਹੈ। ਮੌਜੂਦਾ ਟੋਕਨ ਅਤੇ ਡਾਊਨਲੋਡ ਬਚੇ ਰਹਿੰਦੇ ਹਨ।

```sh
git clone https://github.com/origami-ltd/stremio-local-debrid.git
cd stremio-local-debrid
npm ci
npm run setup
```

```sh
npm run setup -- --no-service
npm start
```

## ਟੀਵੀ ਜੋੜੋ

state/status-url.txt ਵਿੱਚ ਸੰਭਾਲਿਆ ਪਤਾ ਖੋਲ੍ਹੋ, ਭਾਸ਼ਾ ਚੁਣੋ ਅਤੇ Stremio ਵਿੱਚ ਇੰਸਟਾਲ ਕਰੋ ਦਬਾਓ, ਜਾਂ ਐਡਆਨ ਪਤਾ ਇੰਸਟਾਲੇਸ਼ਨ ਖੇਤਰ ਵਿੱਚ ਪੇਸਟ ਕਰੋ। ਉਸੇ ਖਾਤੇ ਨਾਲ ਟੀਵੀ ਦੇ ਐਡਆਨ ਤਾਜ਼ਾ ਕਰੋ ਜਾਂ Stremio ਮੁੜ ਖੋਲ੍ਹੋ। ਫਿਲਮ ਜਾਂ ਐਪੀਸੋਡ ਲਈ ਸਥਾਨਕ ਕੈਸ਼ ਸਰੋਤ ਚੁਣੋ। ਅਸਲੀ ਸਰੋਤ ਖੋਲ੍ਹਣ ਵਾਲੇ ਜੰਤਰ ਉੱਤੇ ਚੱਲਦੇ ਹਨ। ਖਾਤੇ ਦੇ ਐਡਆਨ ਹਰ 60 ਸਕਿੰਟ ਵਿੱਚ ਸਿੰਕ ਹੁੰਦੇ ਹਨ।

## ਕੈਸ਼ ਅਤੇ ਪਲੇਬੈਕ

ਪਲੇਅਰ ਬੰਦ ਹੋਣ ਮਗਰੋਂ ਡਾਊਨਲੋਡ ਜਾਰੀ ਰਹਿੰਦਾ ਹੈ ਅਤੇ ਸਰਵਰ ਮੁੜ ਚਾਲੂ ਹੋਣ ਉੱਤੇ ਬਹਾਲ ਹੁੰਦਾ ਹੈ। ਸਿਰਫ਼ ਚੁਣੀ ਫਾਈਲ ਡਾਊਨਲੋਡ ਹੁੰਦੀ ਹੈ। ਮੂਲ ਕੈਸ਼ 100 GiB ਹੈ ਅਤੇ 10 GiB ਖਾਲੀ ਰੱਖੀ ਜਾਂਦੀ ਹੈ; ਲੋੜ ਪੈਣ ਉੱਤੇ ਘੱਟ ਵਰਤੇ ਪੂਰੇ ਟੋਰੈਂਟ ਹਟਦੇ ਹਨ। ਸ਼ੁਰੂਆਤ peers ਅਤੇ ਨੈੱਟਵਰਕ ਉੱਤੇ ਨਿਰਭਰ ਹੈ। ਟੀਵੀ ਵੀਡੀਓ ਡੀਕੋਡ ਕਰਦੀ ਹੈ; ਟ੍ਰਾਂਸਕੋਡਿੰਗ ਨਹੀਂ ਹੁੰਦੀ। ਕੰਪਿਊਟਰ ਜਾਗਦਾ ਅਤੇ ਪਹੁੰਚਯੋਗ ਰੱਖੋ। IP ਬਦਲੇ ਤਾਂ baseUrl ਠੀਕ ਕਰਕੇ ਐਡਆਨ ਮੁੜ ਇੰਸਟਾਲ ਕਰੋ।

## ਨਿੱਜਤਾ ਅਤੇ ਲਾਇਸੈਂਸ

ਐਡਆਨ URL ਵਿੱਚ ਪਹੁੰਚ ਟੋਕਨ ਹੈ; ਇਸਨੂੰ ਨਿੱਜੀ ਰੱਖੋ। ਖਾਤੇ ਦੀ ਖੋਜ ਮੌਜੂਦਾ ਸਥਾਨਕ Stremio ਪ੍ਰੋਫਾਈਲ ਪੜ੍ਹਦੀ ਹੈ ਅਤੇ ਸੈਸ਼ਨ ਕੁੰਜੀ ਸਿਰਫ਼ ਅਧਿਕਾਰਤ API ਨੂੰ ਭੇਜਦੀ ਹੈ, ਇਸਦੀ ਕਾਪੀ ਨਹੀਂ ਰੱਖਦੀ। ਐਡਆਨ ਪਤੇ ਨਿੱਜੀ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ। ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਮੀਡੀਆ ਕੈਟਾਲਾਗ ਜਾਂ ਟੈਲੀਮੈਟਰੀ ਨਹੀਂ ਹੈ। BitTorrent peers ਕੰਪਿਊਟਰ ਦਾ IP ਦੇਖ ਸਕਦੇ ਹਨ। ਅਧਿਕਾਰ ਵਾਲੀ ਸਮੱਗਰੀ ਵਰਤੋ। MIT-PoU ਆਟੋਮੈਟਿਕ ਸਿਸਟਮਾਂ ਲਈ ਵਰਤੋਂ ਦਾ ਰਿਕਾਰਡ ਅਤੇ ਸਿਹਰਾ ਲਾਜ਼ਮੀ ਕਰਦਾ ਹੈ।
