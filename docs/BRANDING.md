# Branding

The logo is an LD monogram with a violet, indigo and blue gradient on a transparent background. The master PNG is [public/assets/logo.png](../public/assets/logo.png). It is used by both manifests and the installation portal.

Generated with the built-in ImageGen tool through the Codex `imagegen` skill. The flat monogram was generated first; the selected edit added the requested gradient. No external image provider was used.

## Monogram prompt

Design one finished professional logo icon for the open-source project Stremio Local Debrid, a local torrent cache on a computer that streams to a television. New independent direction: a bold, compact geometric typographic LD monogram. Precisely readable capital L and capital D interlocked with elegant negative space, flat solid violet ink #7C5CFA on transparent background, no surrounding shape. Premium modern technology wordmark craftsmanship, unusually simple silhouette, thick clean strokes, optical balance, legible at 32 pixels, centered ample transparent padding, square 1024x1024 composition. Deliver ONLY this one logo symbol, no text caption, no scene, no mockup, no gradients, no shadows, no 3D, no paper folds, no play triangles, no arrows, no download tray, no clouds, no TV or computer pictograms, no multiple variants. The recognizable two-letter LD monogram itself must be the entire logo.
