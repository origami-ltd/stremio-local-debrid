# Changelog

## 1.2.0

- Public self-hosting project under Origami Ltd with MIT-PoU licensing.
- Dashboard, stream labels, errors and installation guides in all 51 locales from the pinned Stremio interface translation registry, including right-to-left layout.
- Automatic startup at login on macOS, Linux and Windows, with a service removal command that preserves cache and state.
- Public installation/configuration portal, discovery manifest, CI and GitHub Pages publication.

## 1.1.0

- Discover the macOS Stremio 5 account's installed addons and synchronize changes every 60 seconds.
- Convert compatible torrent hashes, magnets and `.torrent` sources from modern and legacy HTTP addons.
- Preserve configured provider URLs, private torrent metadata and web seeds; deduplicate torrent/file pairs and combine trackers.

## 1.0.0

- Local computer torrent downloads with HTTP range streaming to a TV.
- Single-file selection, continued background downloads, restart recovery and completed-file cache reuse.
- Cache limits, free-space reserve, completed-torrent eviction and macOS startup.
